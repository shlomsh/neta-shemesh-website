# Tech-debt refactor plan (behaviour-neutral) — netta-shemesh-website

Audit of the working tree as-is on 2026-10-09 (branch `claude/netashemesh-visual-improvements-63836a`, uncommitted, mid typography migration). Read-only; nothing in the repo was touched. Line numbers are from the working tree at audit time (`globals.css` was being edited concurrently, so its numbers are approximate).

## 1. Executive summary

- Scope: 72 `src` TS/TSX files (60 component files), 4,092 lines (3,855 excluding blog post content); 18 vitest files / 954 lines; 6 Playwright specs. No `clsx`/`cva`/`tailwind-variants`/`tailwind-merge` dependency, so every proposal uses plain TS lookup maps and a 6-line `cx()`.
- Biggest structural debt: **9 hand-written "one-screen" section shells** (12x `min-h-[100svh]`, 6x `lg:h/min-h-[max(100svh,720px)]`+`lg:py-12`), **7 raw `<section>`s that bypass `Section`** (Contact x2, Hero, Testimonials x3, Expertise), plus 4x `-mt-px` seams, 4x `px-[clamp(24px,5vw,80px)]`, 4x `py-[clamp(56px,8vw,120px)]` pasted as className strings.
- Boundaries: `About.tsx` (337 lines) is really 4 sections; `Testimonials.tsx` (187) is CTA band + gallery + a hidden testimonials block; `HeroNav` (220) lives in `hero/` but is also the blog header and mixes nav, overlay, focus trap, scroll lock and 2 inline SVGs. 7 files exceed 150 lines; 23 component files are <=25-line single-use wrappers (granularity is inconsistent).
- Repeated patterns: 66 arbitrary `[var(--color-*)]` utilities (21 distinct, all expressible as `text-plum`/`bg-cream`), 27 redundant `dir="rtl"` (html already rtl), 21 `text-right`, 4 identical 9-line mask-icon style objects, ~10 photo-frame variants, 5 copies of the `SectionTitle` class lockup, 3 copies of the `<main>` shell, 40 `ScrollReveal` calls (11 with a no-op `delay={0}`).
- Single-source violations: phone appears 7x in 3 formats across 4 files, email 3x, street address 3x (incl. map query), brand name 32x; **26 Canva-export ids** (18 live in DOM, 8 dead/hidden/CSS-only) referenced by 3 Playwright specs and 5 unit tests; Service descriptions duplicated between `expertiseData.ts` and the JSON-LD in `layout.tsx`.
- Dead code: ~370 dead source lines (hidden testimonials subtree 129 + 103 lines, `SuccessStories`, `Badge`, `layout/FooterReveal`, `layout/StepCard` shim, `footer/FooterReveal` pass-through), 1 dead CSS block keyed to a Canva id, 1 write-only CSS var, 4 unused colour aliases, 8 unreferenced public assets, 8 tracked Canva-era `scratch/` scripts (~300 lines), tracked-but-gitignored `test.txt`.
- Tests: 127 `className` references and 126 `toContain('…')` string assertions in unit tests, 4 tests that `readFileSync` source files, 1 test with zero assertions, 2 duplicate footer tests, the same boilerplate stubs in 5 files; Playwright: `TARGET_URL` re-declared in 6 specs, port 3000 hard-coded in the config, 2 specs that will fail against current code (see T2); CI runs neither lint, `tsc` nor vitest.
- Docs lie: `agents.md` (311 lines) is ~60% Canva-engine history; `primitives/README.md` documents 4 primitives that do not exist.
- Expected outcome if all 4 batches land: ~-700 net source lines, 0 pixel diff at 1280x900 and 375x812, one place for contact facts / ids / section geometry, tests that assert structure (`data-bg-tone`, `data-fit`, roles, hrefs) instead of class strings.
- Explicitly OUT of scope (would change pixels or are open owner decisions): `next/image` vs `<img>` unification, removing `-mt-px` seams (roadmap #2), making the About portrait actually sticky, mauve-contrast decision, placeholder social links, README "15 years" vs "14 years".

4. Pixel diff (no extra deps; PIL is installed): 
   ```
   python3 -I - <<'EOF'
   import sys, glob, os
   from PIL import Image, ImageChops
   a, b = sys.argv[1], sys.argv[2]   # dirs
   bad = 0
   for f in sorted(glob.glob(os.path.join(a, '*.png'))):
       g = os.path.join(b, os.path.basename(f))
       if not os.path.exists(g): print('MISSING', g); bad += 1; continue
       x, y = Image.open(f).convert('RGB'), Image.open(g).convert('RGB')
       if x.size != y.size: print('SIZE', f, x.size, y.size); bad += 1; continue
       box = ImageChops.difference(x, y).getbbox()
       if box: print('DIFF', os.path.basename(f), box); bad += 1
   print('OK' if not bad else f'{bad} differing files')
   EOF
   ```
